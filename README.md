# FieldTrack

## Purpose
An Android field-tracking application for location-aware workflows and field data collection.

## Architecture
This is the initial project scaffold. It is intentionally minimal:

- **Language / UI toolkit:** Kotlin with Jetpack Compose (no XML view layer).
- **Build system:** Gradle with the Kotlin DSL (`.kts` build files).
- **Module layout:** single `:app` application module — no multi-module split
  yet, since there is no functionality to separate.
- **Package root:** `com.synkstack.fieldtrack`
  - `MainActivity.kt` — single-activity entry point that hosts Compose content.
  - `ui/HomeScreen.kt` — a placeholder landing screen (Scaffold + top bar +
    two lines of text) used to confirm Compose renders correctly.
  - `ui/theme/` — standard Material 3 theme setup (`Color.kt`, `Type.kt`,
    `Theme.kt`) with light/dark and dynamic-color support.
- **Resources:** standard `res/values` (`strings.xml`, `colors.xml`,
  `themes.xml`) plus an adaptive launcher icon.
- **Tests:** one placeholder local unit test (`src/test`) and one placeholder
  instrumented test (`src/androidTest`), wired to the standard JUnit /
  AndroidX Test / Espresso setup, to confirm both test source sets build.

No feature logic exists yet — no auth, backend integration, persistence,
maps, analytics, notifications, live location tracking, or sync/upload/retry
logic. Those are deliberately out of scope for this setup task and will be
layered on in subsequent sprints.

## Setup
Requirements: JDK 17, Android SDK (compileSdk 34), and network access to
Google's and Maven Central's artifact repositories.

Build from the command line:

```bash
./gradlew assembleDebug
```

Run unit tests:

```bash
./gradlew testDebugUnitTest
```

Run instrumented tests (requires a connected device or emulator):

```bash
./gradlew connectedDebugAndroidTest
```

> **Note:** `gradle/wrapper/gradle-wrapper.jar` (the wrapper's binary
> launcher) is not included in this scaffold, since it must be generated by
> an actual Gradle installation rather than hand-authored. Before relying on
> `./gradlew`, run `gradle wrapper --gradle-version 8.7` once from a machine
> with Gradle installed (or open the project in Android Studio, which will
> provision the wrapper automatically).
